# 🎓 TeacherTrainer — Тренажёры для педагогов

Кроссплатформенные интерактивные тренажёры, помогающие учителям отрабатывать профессиональные навыки в безопасной среде без риска для реального учебного процесса.

🖥️ **Платформы:** Windows, Android  
🎯 **Цель:** Практико-ориентированное развитие педагогических компетенций.

### 🔑 Ключевые сценарии
- Коммуникация с учениками и родителями (разбор конфликтов, этические кейсы)
- Практика работы с цифровыми платформами и электронными журналами
- Тайм-менеджмент, подготовка к аттестации, инклюзия
- Анализ решений и персональные рекомендации

### 🛠 Технологический стек
`Python` • `Kivy` • `KivyMD` • `SQLite` • `GitHub Actions (CI/CD)`

### 🚀 Статус
🟡 Активная разработка. Архитектура и первые прототипы сценариев.  
✅ Открыт для контрибьюторов, тестировщиков и педагогов-методистов.
